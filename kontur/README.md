# Контур для Telegram Mini App

Одна статическая веб-сборка. В `index.html` находятся интерфейс, логика, шрифты системы и демонстрационное фото. `sw.js` кэширует страницу для автономного повторного открытия в браузерах с поддержкой Service Worker. Устанавливать пакеты или запускать сервер приложения не требуется.

## Подключение к боту

1. Распакуйте архив в корень статического HTTPS-хостинга. Файлы `index.html` и `sw.js` должны находиться рядом.
2. Откройте публичный HTTPS-адрес в обычном браузере и убедитесь, что загрузился «Контур».
3. В [@BotFather](https://t.me/BotFather) выполните `/setmenubutton`, выберите своего бота, задайте текст **Контур** и укажите HTTPS-адрес. Для кнопки запуска в профиле бота используйте настройку **Main Mini App**. [Инструкция Telegram](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button)
4. Откройте кнопку у своего бота на телефоне и на ПК.

Если бот уже отправляет кнопки, можно передать его коду кнопку `web_app` с тем же адресом. [Формат WebAppInfo](https://core.telegram.org/bots/api#webappinfo)

```json
{
  "inline_keyboard": [
    [
      {
        "text": "Открыть Контур",
        "web_app": { "url": "https://example.org/kontur/" }
      }
    ]
  ]
}
```

## Что работает локально

- Демонстрационная разведка, порции поиска, фильтры и База с ручным добавлением заведений.
- Черновики на русском и английском, тестовое окно Telegram, история касаний и статусы.
- Редактор демосайта, предпросмотр для двух ширин и экспорт HTML. ZIP, папка и HTML импортируются как статические страницы. Скрипты импортированных сайтов удаляются, поддерживаются локальные изображения, стили и шрифты.
- Данные записываются в хранилище браузера. У каждого устройства и профиля браузера своё хранилище. Очистка данных сайта удалит локальный кабинет.
- **Создать ссылку** упаковывает снимок демосайта в сам адрес. Получатель может открыть его на том же веб-хостинге, даже если у него пустая База. После правки создайте новую ссылку. Для больших страниц и загруженных фотографий используйте экспорт HTML. Счётчик в кабинете отражает открытия или переходы только на текущем устройстве.
- При входе из Telegram приложение может загрузить официальный SDK для разворачивания окна, системной кнопки «Назад» и открытия ссылок. Основные функции от SDK не зависят. Для первого открытия Mini App требуется доступ к HTTPS-хостингу. Повторный запуск без сети зависит от кэша и поддержки Service Worker в клиенте.
- Рабочие запросы к картам, Gemini, синхронизация между устройствами и общая статистика потребуют отдельного серверного приложения.

## Проверка сборки

Пройден сценарий от поиска до публикации и экспорта демо в Chromium на ПК и при ширине 390 px. Проверены отдельный профиль получателя, перезагрузка без сети после кэширования, импорт ZIP с относительным CSS и локальное сохранение. Интеграция интерфейса Telegram проверена на тестовой реализации SDK. Реальный запуск внутри вашего бота выполняется после настройки HTTPS-адреса в BotFather.

Встроенная библиотека fflate 0.8.2 распространяется на условиях MIT. Лицензия лежит рядом с приложением.
