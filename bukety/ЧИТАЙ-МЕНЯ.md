# Букеты и секреты — сайт цветочного магазина

Одна страница, один файл. Ни сборки, ни зависимостей.
Открывается двойным щелчком по `index.html`; для публикации достаточно
залить папку целиком на любой хостинг (GitHub Pages, Timeweb, Reg.ru).

```
bukety/
  index.html      ← сайт целиком: разметка, стили, скрипт
  fonts/          ← Poiret One (имена букетов), Onest (текст), Marck Script («секрет»)
  img/            ← вырезанные цветы (webp с прозрачностью), фото, лента satin.webp, og.jpg
  DESIGN.md       ← описание визуальной системы
  PRODUCT.md      ← что известно о магазине и что нельзя выдумывать
```

## Что заменить перед запуском

1. **Фото букетов** — сейчас стоят стоковые заготовки с Unsplash (в `alt`
   подписаны «образец»). Цветы в коробках — это вырезанные по контуру
   картинки с прозрачным фоном (webp с альфа-каналом): коробка держит их,
   фон страницы просвечивает. Чтобы заменить на свои, сфотографируйте букет
   на ровном светлом фоне, уберите фон (любой сервис удаления фона), сохраните
   PNG или webp с прозрачностью и положите в `img/` под теми же именами:
   `sky-800`/`sky-1200` (первый экран и первая коробка), `sun`, `tender`,
   `jam`, `violet`, `blueish` — по 520 и 900 px шириной. Обычное
   прямоугольное фото тоже встанет, но будет выглядеть как карточка, а не
   как цветы в коробке. Фото для раздела «Как заказать» (`hands-700`/`-1100`,
   квадрат) — обычное. `og.jpg` (1200×630) пересоберите: откройте
   `index.html?og&nobar` в окне 1200×630 и сделайте снимок.
2. **Состав букетов** на сайте не указан (в «секретах» стоит честное
   «Состав подбирают по сезону и вашему бюджету»). Если хотите — впишите
   настоящий состав каждого букета в строку `box__mix` внутри коробки.
3. **«Секреты»** (рукописные строки внутри коробок) — авторский текст под
   имя букета. Правьте свободно; «Нежность есть во всех шести категориях» —
   это факт из вашего каталога на Яндекс Картах.
4. **Цены** нигде не стоят числом — по вашей же карточке («указана
   минимальная стоимость… уточняйте по телефону»). Если появятся «от … ₽»,
   строка `box__price` в каждой коробке — то место.

## Как устроено

- Все кнопки «Позвонить» — `tel:`-ссылки на +7 (917) 914-48-86.
- Коробка на витрине открывается по кнопке «Открыть секрет»: крышка
  приподнимается, из-под коробки выезжает записка. На телефоне витрина —
  горизонтальная полка, листается пальцем; от 600 px — сетка.
- Цветы «поднимаются» из коробки при появлении в кадре; при
  `prefers-reduced-motion` анимации и бегущая лента выключены.
- На телефоне после первого экрана появляется нижняя лента «Позвонить»;
  чип «сейчас открыто / закрыто» считается по московскому времени.
- Служебные параметры адреса: `?nobar` (без нижней ленты), `?og` (только
  первый экран, для превью 1200×630), `?open=2` (открыть секрет
  второй коробки — посмотреть состояние).
