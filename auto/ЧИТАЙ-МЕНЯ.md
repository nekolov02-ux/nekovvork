# Автомастерская — сайт

Одна страница, один файл. Ни сборки, ни зависимостей, ни базы данных.
Открывается двойным щелчком по `index.html`.

```
auto/
  index.html      ← сайт целиком: разметка, стили, скрипты
  fonts/          ← шрифты Oswald и Golos Text, лежат рядом
  img/            ← фотографии
  ЧИТАЙ-МЕНЯ.md   ← этот файл
```

## Что нужно заполнить вам

Я не выдумываю факты о мастерской. Везде, где на сайте стоит пунктирный
прочерк, ждёт ваша правда. В исходнике каждое такое место помечено
комментарием `ЗАГЛУШКА` — ищите поиском по файлу.

| Где | Что стоит сейчас | Что подставить |
|---|---|---|
| Везде | Название «Ось» | Ваше название. Это рабочая заглушка, не предложение |
| Первый экран | «на ——» | Улицу, чтобы адрес читался с первого экрана |
| Первый экран, подвал, нижняя панель | `href="tel:"` пустой | Телефон: `tel:+7XXXXXXXXXX` и текст рядом |
| Первый экран | «Ежедневно ——» | Часы работы одной строкой |
| Что делаем | Шесть работ | Ваш список: что-то убрать, что-то дописать |
| Что делаем | «от —— ₽» | Цены «от» либо уберите колонку целиком |
| Мастерская | Стоковые снимки | Фотографии вашего цеха и ваших людей |
| Приехать | «ул. ——, ——» | Адрес |
| Приехать | Город, ориентир, заезд | По каким приметам вас находят и откуда заезжать |
| Приехать | Кнопка «Открыть на карте» | Ссылку на вашу карточку в Яндекс.Картах или 2ГИС |
| Приехать | Часы работы | Три строки расписания |

## Тексты, которые стоит перечитать

Это правда общего характера — так работает любая честная мастерская.
Если у вас иначе, поменяйте, иначе первый же клиент поймает на слове:

- «Назовём цену до начала работы» — первый экран и шаг 2
- «Не начинаем, пока не согласуете» — шаг 2
- «Звоним и спрашиваем, а не дописываем в счёт» — шаг 3
- «Показываем снятое, отдаём старые детали» — шаг 4 и первый экран
- «Без записи или по звонку» — первый экран и шаг 0

## Чего на сайте намеренно нет

Стажа на рынке, числа отремонтированных машин, отзывов, гарантийных
сроков, логотипов марок. Ничего из этого не подтверждено, поэтому
и не написано. Появятся настоящие цифры — добавим.

## Как поменять фотографии

Положите свои снимки в `img/` и замените имена файлов в `index.html`.
Каждая фотография подключена в трёх размерах — для телефона, для
планшета и для большого экрана:

```
img/shop-640.webp  img/shop-1100.webp  img/shop-1800.webp   ← общий вид цеха
img/master-640.webp  img/master-1100.webp                   ← мастер за работой
img/wheel-640.webp   img/wheel-1100.webp                    ← колесо и гайковёрт
```

Если размер один — поставьте его во все три места, сайт не сломается.
Не забудьте описание в `alt=""`: его читают вслух незрячим и видят те,
у кого картинка не загрузилась.

Нынешние снимки взяты с Unsplash: они бесплатны и для коммерческого
использования, но это чужой цех. Свои фотографии работают сильнее —
именно по ним человек решает, ехать к вам или нет.

## Про колесо

Колесо в первом экране выкатывается слева и красит за собой осевую
линию. Оно не гифка и не библиотека: это нарисованная векторная
картинка, а качение считается по настоящей геометрии — сколько
проехало, столько и провернулось, без проскальзывания.

Если у посетителя в системе включено «уменьшать движение», колесо
просто стоит на месте. Так же страница ведёт себя без JavaScript.
Это рабочее состояние, а не поломка.

## Как выложить сайт

Сейчас сайт настроен на адрес **https://nekovvork.ru/auto/**. Папка `auto/`
кладётся целиком в репозиторий, из которого работает nekovvork.ru, — все
пути внутри относительные, поэтому ничего править не нужно.

Файл `CNAME` должен остаться один и только в корне репозитория. Копировать
его в `auto/` нельзя: GitHub Pages берёт домен из корня, и второй файл
собьёт настройку.

### Если сайт переедет на свой домен

В `index.html` есть две строки с полным адресом — их читают телеграм,
вотсап и ВК, когда строят превью ссылки:

```
<meta property="og:url"   content="https://nekovvork.ru/auto/">
<meta property="og:image" content="https://nekovvork.ru/auto/img/og.jpg">
```

Здесь нужен именно полный адрес, относительный путь мессенджеры
не понимают. При переезде поменяйте обе строки на новый домен, иначе
в превью будет подтягиваться картинка со старого места. Найти их
можно по пометке `ЗАГЛУШКА` рядом.

Картинка превью — `img/og.jpg`, 1200×630. Когда замените фотографии
на снимки своего цеха, пересоберите и её в том же размере.
