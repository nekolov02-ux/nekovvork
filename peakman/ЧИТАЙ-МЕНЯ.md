# Peakman — сайт барбершопа

Одна страница, один файл. Ни сборки, ни зависимостей.
Открывается двойным щелчком по `index.html`; для публикации достаточно
залить папку целиком на любой хостинг (GitHub Pages, Timeweb, Reg.ru).

```
peakman/
  index.html      ← сайт целиком: разметка, стили, скрипт
  fonts/          ← Sofia Sans Extra Condensed и Geologica, лежат рядом
  img/            ← фото (webp) и og.jpg для превью в мессенджерах
  DESIGN.md       ← описание визуальной системы
```

## Что заменить перед запуском

1. **Фото интерьера** — сейчас стоят стоковые заготовки, подписанные
   «образец». Положите свои в `img/` под теми же именами
   (`a-tools`, `b-window`, `c-room`, ширины 700 и 1200 px, webp) — или
   поменяйте пути в блоке `<section class="atm">`. Подпись «· образец» в
   `<figcaption>` уберите. `og.jpg` (1200×630) — тоже своё.
2. **Отзывы** — четыре настоящих, с Яндекс Карт (январь 2025), дословно.
   Появятся новые — добавьте `<li>` по образцу в `<section class="log">`.
3. **Скидка 20% на первое посещение** — такая новость висит на Яндекс
   Картах с января 2025. На сайт не ставил: если акция жива, скажите —
   добавлю строкой на лист с ценами.

## Что уже настоящее

Адрес, телефон, часы (ежедневно 11:00–19:00), цены, рейтинг 4,3, отзывы,
«можно с собакой», ориентир «170 м от автовокзала» и ссылка на запись
`https://dikidi.net/1769959` — используются во всех кнопках «Записаться».
Если ссылка изменится — найдите-замените её по файлу (5 вхождений).

## Как устроено

- Кнопки записи ведут на Dikidi в новой вкладке; телефон — `tel:`-ссылка.
- Горизонтали в шапке — SVG, сгенерированный один раз; параллакс и
  «альтиметр» (шкала высоты по скроллу) — 40 строк JS внизу файла.
  При `prefers-reduced-motion` анимации отключены.
- На телефоне после первого экрана появляется нижняя панель
  «Записаться / позвонить»; на десктопе кнопка в шапке.
- Служебные параметры адреса для скриншотов: `?nobar` (без нижней панели),
  `?og` (без шапки, для превью 1200×630), `?freeze=1300` (остановить
  анимацию на миллисекунде — посмотреть кадр появления логотипа).
