# nekovvork group — сайт студии

Одна страница, один файл. Ни сборки, ни зависимостей, ни базы данных.
Открывается двойным щелчком по `index.html`.

```
nekovvork/
  index.html      ← сайт целиком: разметка, стили, скрипты
  _1bit.html      ← отклонённая сборка «1 бит», лежит про запас
  img/            ← фотографии
  ЧИТАЙ-МЕНЯ.md   ← этот файл
```

## Что нужно заполнить вам

Я не выдумываю факты о вашей команде. Ниже — места, где стоит правда общего
характера; когда у вас появятся конкретные цифры, замените текст.

| Где | Что сейчас написано | Что стоит подставить |
|---|---|---|
| Секция «Как это происходит», шаг 02 | «Называем срок и цену до начала работы» | Ваши реальные вилки сроков и цен, если готовы их публиковать |
| Секция «Напишите» | «Нас немного, и сайт делает тот же человек, с которым вы переписываетесь» | Сколько вас и кто за что отвечает, если захотите назвать |
| Секция «Что получилось у КофеР» | Один кейс | Изюм и «Сладости и Радости», когда выложите их |

**Чего на сайте намеренно нет:** количества проектов, лет на рынке, числа
клиентов, отзывов, логотипов заказчиков. Ничего из этого не подтверждено,
поэтому и не написано.

## Как добавить вторую и третью работу

В `index.html` найдите комментарий:

```
▼▼ МЕСТО ПОД СЛЕДУЮЩИЕ РАБОТЫ ▼▼
```

Скопируйте блок `<div class="case">…</div>`, лежащий выше, положите рядом
скриншот в `img/`, поменяйте ссылку, подпись `alt` и четыре факта.
Работы `izyum.html` и `sladosti-i-radosti.html` пока не задеплоены — сначала
выложите их, чтобы ссылка вела на живой сайт, а не в никуда.

## Цвета

Голубой снят пипеткой с радужки кота на геройской фотографии и поднят по
насыщенности. Значений два, потому что одно не проходит по контрасту в обеих
темах:

| | Ночь | День |
|---|---|---|
| крупное: заголовки, иконки, рамки | `#3FB8EC` | `#1783B4` |
| мелкое: подписи, номера шагов, заливки кнопок | `#3FB8EC` | `#14688F` |

Всё остальное ахроматично: тёплый почти-чёрный `#0D0C0B` и костяной `#F5F2EC`
меняются ролями при переключении темы. Если поменяете геройский кадр, голубой
стоит пересчитать под новый — он держит связь фотографии и интерфейса.

**Кошачьи уши** на голубых кнопках нарисованы в разметке (`<span class="ears">`)
и красятся тем же цветом, что и заливка кнопки, поэтому читаются как её часть.
Чтобы добавить их ещё куда-то, повесьте на ссылку класс `btn--ears` и вложите
внутрь тот же `<span>`.

## Как выложить на GitHub Pages

```bash
cd nekovvork && git init && git add . && git commit -m "Сайт студии"
```

Дальше создайте пустой репозиторий на GitHub, свяжите с ним папку и включите
Pages в настройках репозитория: Settings → Pages → Source → ветка `main`,
папка `/ (root)`. Через минуту сайт будет по адресу
`https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Что стоит знать

- **Шрифты лежат в папке `fonts/`,** а не подгружаются с чужого сервера:
  91 КБ на обе гарнитуры со всеми весами и кириллицей. Сайт выглядит
  одинаково при любой сети и в любой стране.
- **Тема запоминается** в браузере посетителя, а при первом заходе берётся из
  настроек его системы.
- **Движение выключается само** у тех, кто отключил анимации в системе:
  ни параллакса, ни бегущей строки, ни появления секций.
- **Формы обратной связи нет** намеренно: без сервера она бы только создавала
  видимость отправки. Вся связь идёт в телеграм.
