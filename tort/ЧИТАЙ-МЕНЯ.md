# Конструктор торта — шаблон сайта-визитки кондитера

Одна страница, один файл. Ни сборки, ни зависимостей.
Открывается двойным щелчком по `index.html` (картинки и шрифты лежат рядом);
для публикации достаточно залить папку целиком на любой хостинг
(GitHub Pages, Timeweb, Reg.ru). Единственная внешняя библиотека — html2canvas
с cdnjs — подгружается только в момент нажатия «Сохранить картинку».

```
tort/
  index.html        ← сайт целиком: разметка, стили, скрипт и CONFIG
  fonts/            ← Playfair Display (заголовки, цены), Manrope (текст), субсеты с ₽
  img/
    cake/           ← слои торта (WebP с прозрачностью), см. ниже
    thumb-*.webp    ← миниатюры вариантов (320 и 640 px, квадрат)
    work-*.webp     ← галерея работ (560 и 900 px, 4:5)
    og.jpg          ← превью для ссылок в мессенджерах, 1200×630
  DESIGN.md         ← описание визуальной системы
  PRODUCT.md        ← что известно о продукте и что нельзя выдумывать
```

## Под нового кондитера меняются две вещи

### 1. Объект `CONFIG` — первый блок внутри `<script>`

Всё, что зависит от конкретной кондитерской, лежит там. Логику ниже трогать
не нужно.

| Поле | Что это |
|---|---|
| `brand.name` | название — в шапке, карточке, подписи |
| `brand.title`, `brand.lead`, `brand.note` | заголовок, подводка и подпись первого экрана (в `title` можно оставить `<em>…</em>` — слово выделится малиновым курсивом) |
| `brand.city`, `brand.site` | город в подвале, адрес сайта на карточке |
| `contacts.phone` | телефон как показывать; ссылка `tel:` строится сама |
| `contacts.whatsapp` | номер цифрами без «+» (`79001234567`). Пусто — кнопок WhatsApp не будет |
| `contacts.telegram` | имя пользователя без «@». Пусто — кнопок Telegram не будет |
| `contacts.instagram` | имя без «@»; пусто — строки не будет |
| `contacts.address`, `contacts.hours` | строки в блоке «Заказать» |
| `order.showPrices` | `false` — цены исчезают везде: в вариантах, в строке состава, на карточке и в сообщении |
| `order.currency`, `order.priceNote` | знак валюты и пояснение под ценой на карточке |
| `order.message` | шаблон сообщения в мессенджер. `{cake}` → состав, `{price}` → строка из `order.priceLine` (пустая при `showPrices:false`) |
| `order.emptyMessage` | сообщение, если клиент нажал кнопку, ничего не собрав |
| `ui.*` | заголовки и подписи разделов, подсказка «Начните с коржа» |
| `showcase` | какой торт показать на первом экране (id из шагов) |
| `steps[]` | три шага: `base` (корж), `filling` (начинка), `decor` (декор) |
| `gallery[]` | фото работ: имя файла без размера и расширения, `alt`, название, примечание |

Каждый вариант внутри шага:

```js
{ id:"honey", name:"Медовик", desc:"тонкие медовые коржи", price:2600,
  thumb:"img/thumb-honey",      // файлы thumb-honey-320.webp и thumb-honey-640.webp
  layer:"sponge-honey" }        // файл img/cake/sponge-honey.webp
```

- `price` у коржа — базовая цена торта, у начинки и декора — надбавка;
  карточка показывает сумму.
- У варианта «Надпись» стоят `text:true`, `textDefault` (что написано, пока
  клиент не ввёл своё) и `textMax` (длина, чтобы поместилось на табличку).
- Переименовать «Начинка» в «Крем» — поле `title` у шага; слово для строки
  «осталось: …» — `label`.

### 2. Палитра и шрифты — блок `/* БРЕНД */` в начале `<style>`

```
--paper        фон страницы (кремовая бумага)
--paper-deep   фон витрины с карточкой
--cream        карточка, плашки вариантов
--caramel      подписи-акценты, орнамент карточки
--caramel-deep то же для мелкого текста (нужен контраст ≥ 4.5:1 с фоном)
--berry        единственный цвет действия: кнопки, выбранный вариант, галочки
--berry-deep   его тёмный тон (наведение, мелкий текст)
--berry-soft   лёгкая дымка (выделение текста, поле ввода в фокусе)
--cocoa        основной текст и тёмная секция «Заказать»
--cocoa-soft   вторичный текст
--fd / --ft    шрифт заголовков / шрифт текста
```

Сменить бренд = поменять 6–8 значений. Например, фисташковая кондитерская:
`--berry:#4F7A3A; --berry-deep:#3B5E2B; --berry-soft:#DDEBD2` — и весь сайт
перекрасится, включая карточку и кнопки. Тёмная секция контактов возьмёт
`--cocoa`; если бренд светлый, можно поставить туда глубокий цвет бренда.

Шрифты: положите свои `.woff2` в `fonts/`, поправьте `@font-face` (первые
строки `<style>`) и переменные `--fd`/`--ft`. Если ставите другой шрифт для
цен — проверьте, что в нём есть знак ₽ (U+20BD); у Google Fonts его нет в
основных субсетах, поэтому здесь лежат отдельные крошечные `*-ruble.woff2`.

## Как устроен торт

Торт — не одна картинка, а стопка WebP-слоёв с прозрачностью одинакового
размера (1400×1138), наложенных друг на друга:

```
img/cake/base.webp            тарелка + «непропечённый» серый силуэт (виден, пока ничего не выбрано)
img/cake/sponge-<id>.webp     корж на срезе — по одному файлу на вариант коржа
img/cake/fill-<id>.webp       прослойки + внешнее покрытие + верх — по одному на начинку
img/cake/decor-<id>.webp      декор сверху — по одному на вариант декора
```

Все слои сделаны из **одного** снимка реального куска торта: регионы среза
(корж, прослойки, покрытие) перекрашены по яркости, поэтому фактура крошки и
крема настоящая, а геометрия у всех вариантов совпадает. Декор — вырезки из
фотографий (малина, мята, роза, грецкий орех) и отрисованные глянцевые подтёки.
Текст на шоколадной табличке рисуется поверх слоя обычным шрифтом, чтобы
html2canvas отдал его в картинку.

**Добавить новый корж или начинку:** нужен новый слой с тем же размером и той
же геометрией — проще всего попросить того, кто делал эти файлы, перекрасить
регион в нужный цвет (это одна строка в скрипте сборки). Потом добавьте вариант
в `CONFIG` со ссылкой на файл и миниатюрой.

**Заменить торт на свой полностью:** снимите свой кусок на ровном светлом фоне
(фронтально, срез к камере), вырежьте фон и нарежьте регионы в любом редакторе
на слои с прозрачностью тех же размеров и имён. Пока файлы называются так же,
код не меняется.

## Что делают кнопки

- **«Собрать свой торт»** — прокрутка к первому шагу.
- **Выбор варианта** — слой торта проявляется, заголовок шага получает
  галочку и строку «Выбрано: … — можно поменять», страница мягко прокручивает
  к следующему шагу. Для «Надписи» открывается поле ввода.
- **«Сохранить картинку»** — html2canvas рендерит карточку в PNG (в 2 раза
  крупнее экрана). На телефоне открывается системное «Поделиться» (в директ,
  сторис, мессенджер); где его нет — окно с картинкой, ссылкой «Скачать» и
  подсказкой «удерживайте, чтобы сохранить».
- **«Заказать в WhatsApp / Telegram»** — открывают чат с уже вписанным
  сообщением: состав, надпись и примерная цена. Текст виден в блоке «Заказать»
  (строка «Текст сообщения»), чтобы клиент знал, что отправит.
- **Нижняя лента** на телефоне показывает, что уже выбрано и что осталось, и
  ведёт к следующему шагу; когда торт собран — к карточке.

## Служебные параметры адреса

- `?b=honey&f=choco&d=berries` — открыть уже собранный торт (id из `CONFIG`);
  `&t=Текст` — надпись. Адрес обновляется сам по мере выбора, так что клиент
  может просто скинуть ссылку на свой торт.
- `?nobar` — без нижней ленты, `?og` — только первый экран (для превью
  1200×630: откройте в окне 1200×630 и сделайте снимок — так собран `img/og.jpg`).
